# 🐾 UrbanMiau

**Proyecto de desarrollo de software – Java**

UrbanMiau es un proyecto de desarrollo de aplicaciones en el que participé durante mi periodo de prácticas del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM).

El proyecto forma parte de mi experiencia formativa en un entorno de trabajo real, donde pude aplicar conocimientos de programación y participar en el proceso de desarrollo de una aplicación.

## 🛠️ Tecnologías

- **Java:** lenguaje de programación utilizado en el proyecto.
- **Git / GitHub:** herramientas de control de versiones y gestión del código.

## 👩‍💻 Mi participación

Durante mi periodo de prácticas participé en diferentes tareas relacionadas con el desarrollo del proyecto:

- Colaboración en el diseño de la aplicación.
- Desarrollo e implementación de funcionalidades.
- Participación en reuniones diarias de seguimiento.
- Colaboración con el equipo de desarrollo.
- Aplicación de conocimientos adquiridos durante el ciclo de DAM.

## 🎓 Contexto del proyecto

Este proyecto está vinculado a mi periodo de Formación en Centros de Trabajo (FCT), realizado entre mayo y junio de 2026.

Fue una oportunidad para conocer la dinámica de trabajo de un equipo de desarrollo y reforzar mis habilidades de programación.
